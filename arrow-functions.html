Arrow Functions

This function takes a mood as a string and then returns a fortune based on that mood or button chosen from my previous project. I just came up with it as it connects to the library liberty project with a fortune machine style example, so it was easy to convert into different function formats.

Named Function

                function getFortune(mood) {
                    return `Your ${mood} fortune is: something strange is coming your way.`; 
                }

                console.log(getFortune("luck"));

Function Expression

                const getFortune = function(mood) {
                    return `Your ${mood} fortune is: something strange is coming your way.`;
                };
            
                console.log(getFortune("luck"));

Arrow Function

                const getFortune = mood => `Your ${mood} fortune is: something strange is coming your way.`;
                        
                console.log(getFortune("luck"));
