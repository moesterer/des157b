Feasibility Report

Technical requirements wise My project isn’t too complicated. There are a lot of parts but a lot of repetition in how users interact with those things and the content will be displayed in a similar manner so the same libraries and code can be used.

Animate on Scroll

The main library I will be using will be animate on scroll. This is mainly for the beginning sequence which will animate the newspapers to be shown on screen as the user scrolls down along with a few decorative background pieces that I will draw that will be animated to move on the page as the user scrolls past certain papers. I am confident that I can figure it out with no to minimal help within the time left.

SVGs and Atropos

For the interactive objects which the user can click on I am planning to stay simple with svgs to click on and an exclamation point to indicate interactable objects in each scene. This is nothing we have not done before in class. Once the object is clicked, I may use the Artopos library for the 3d tangible objects but without the parallax effect. I feel confident as I have already used this library for another project.

Typed.js

I will also most likely use Typed.js to display the main text box at the bottom of the page which will reflect the citizen’s thoughts or observations or any other information relevant to the scene. This is a fairly simple library from the looks of it so it should be feasible to figure out. However this is just extra sauce, the main objective is to get everything I want to include working in order.
